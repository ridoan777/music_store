   [1.3] THIRD-PARTY ADD-ONS:

      [1.3.1] Run this:

         npm i pinia-plugin-persistedstate uniqolor vue-material-design-icons

            - pinia-plugin-persistedstate : A package. Configurable persistence and rehydration of Pinia stores. Pinia states are lost on browser reloads. So a persistences strategy is needed to save them in localStorage (default), sessionStorage, etc.

               Learn more: https://www.npmjs.com/package/pinia-plugin-persistedstate?activeTab=readme

            - uniqolor : A library generating colors from texts.

               Link: https://www.npmjs.com/package/uniqolor

            - vue-material-design-icons : Makes vue components for each icon.

               Link: https://www.npmjs.com/package/vue-material-design-icons
               Demos : https://pictogrammers.com/library/mdi/
